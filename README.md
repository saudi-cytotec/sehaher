# SehaHer — starter static website

Arabic RTL static site scaffold for sehaher.com.

## Files
- Static HTML pages with per-page titles, descriptions, canonical URLs, Open Graph basics.
- `assets/style.css` responsive styles and floating WhatsApp contact link.
- `sitemap.xml`, `image-sitemap.xml`, and `robots.txt`.
- Only the SehaHer logo asset is included; FemSeha images were not copied.

## Before publishing
1. Review all copy and replace placeholders with approved, accurate information.
2. Add your own approved images and regenerate `image-sitemap.xml` with their final URLs.
3. Verify the deployed canonical domain and sitemap URL.
4. Test mobile layout, links, accessibility, and Lighthouse/PageSpeed.
5. Confirm service details and privacy language match actual operations and applicable rules.

## Deploy
This is a static HTML project; it can be deployed on GitHub Pages, Cloudflare Pages, or another static host. No build command is required.
